## Limits to preserve explicitly

Go cross-context method-set matches remain labeled candidates/partial for uncovered function-local types and generic cases. Static call hierarchy is not exhaustive runtime dispatch. Named Go GOOS/GOARCH/tag/cgo contexts now run alongside default views in one provider session. Cross-target execution is rejected, and shared-source renames reject conflicting conditional bindings. The development native profile-selector scenario passes. Conservative rename guards remain necessary where implementation coverage cannot be proven. See the Go package's detailed scope.

Disjoint changed lines in one file can now belong to different named changelists; unassigned lines remain in Default and stale assignments require review. Package initialization, including upgrades/restarts, runs outside the host and workspace locks. Candidate acceptance rechecks package/workspace identity, and disable/workspace replacement/shutdown cancel it. Local archive validation, hashing, and copying still run under the preparation lock and need resource qualification.

The representative source must remain unchanged. Use disposable workspace copies for workflows that create files or run Git mutations. Exclusions, dependency caches and query coverage must be disclosed rather than reduced to improve performance numbers. No percent memory/CPU reduction target is implied by this document.

The final frontend/service test run passes **166/166 across 36 files, with no skips**, including actual MySQL/PostgreSQL/SQLite/Redis. SQL pages bound nested preview content and preserve every query row across pagination. Duplicate query-column names require explicit aliases so object transport cannot silently overwrite values. Raw database-driver cell/member decoding and table-browse materialization happen before preview bounds; these bounds do not promise pre-decode memory protection. Worker tests cover observational readiness timeouts, process-group cleanup, output backpressure and cancellation registration/ID-reuse races. The Rust workspace suite also passes, including regressions that preserve edits accepted during workspace discovery. UI regressions verify synchronous editing locks, rejected close acknowledgements, and streamed hierarchy updates. The final production app and six packages have rebuilt successfully; a fresh development/native run passes all 16 scenarios. Production launch, signature and process-attribution checks pass. Production-native input remains unverified because the UI automation attachment timed out; this does not establish a product input failure.
