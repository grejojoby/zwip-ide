05 / A FEW THINGS TO KNOW

Before you
jump in.

Is this ready to replace my daily IDE?+

This is an active personal preview. Core workflows are implemented and tested, but production-native workflows, accessibility, physical input and repeatable performance measurements still need qualification. See the detailed status.

Is Zwip only for Go?+

No. The core is general-purpose. Go and web development are the initial language packages, and both are optional. Framework and database tools follow the same package model.

What can I navigate?+

Explore declarations, usages, implementations and type or call hierarchies. Language providers report their supported operations and analysis coverage. Static analysis cannot promise exhaustive runtime dispatch.

Can I download a signed release?+

There is no qualified public binary release linked here yet. Build from source for now. Current local app builds use ad-hoc signing and are not Developer ID signed or notarized.

What is outside the first release?+

Java/JVM tooling, integrated browser debugging, remote development, AI features, collaboration and a public plugin marketplace are deferred. Frontend apps run through project scripts; browser debugging uses external DevTools.
