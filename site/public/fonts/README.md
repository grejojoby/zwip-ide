# Font sources

Self-hosted original font files downloaded on 2026-10-13 from the official Google Fonts repository:

- [Instrument Sans variable font](https://github.com/google/fonts/tree/main/ofl/instrumentsans), saved as `instrument-sans.ttf`. Copyright 2022 The Instrument Sans Project Authors. License: `instrument-sans-OFL.txt`.
- [Instrument Serif italic](https://github.com/google/fonts/tree/main/ofl/instrumentserif), saved as `instrument-serif-italic.ttf`. Copyright 2022 The Instrument Serif Project Authors. License: `instrument-serif-OFL.txt`.

Both use the SIL Open Font License 1.1. Font files are unmodified; the local filenames simplify asset references. Keep the corresponding original license files with any redistribution.
